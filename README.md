# 📸 אלבומי המשפחה

אתר שמעצב אלבומי תמונות משפחתיים באופן אוטומטי ומפיק קובץ PDF מוכן להדפסה.

## מה הוא עושה
- **כמה אלבומים** – כל אלבום נשמר בנפרד (בדפדפן, במכשיר שלכם; שום תמונה לא נשלחת לשרת).
- **בחירה חכמה של תמונות** – מזהה תמונות זהות/כמעט זהות (צילומי רצף) ומשאיר רק את הטובה ביותר
  לפי חדות, תאורה, ניגודיות, צבעוניות ורזולוציה. תמונות מטושטשות או חשוכות מסוננות.
  אפשר תמיד ללחוץ על תמונה כדי להכניס/להוציא אותה ידנית.
- **עיצוב אוטומטי** – מסדר לפי תאריך הצילום (EXIF), מחלק לאירועים עם עמודי פתיחה,
  בוחר פריסה לכל עמוד כך שהחיתוך יהיה מינימלי, וממרכז את החיתוך על מרכז העניין בתמונה.
- **5 סגנונות**: קלאסי, מודרני כהה, וינטג׳ פולארויד, צבעוני (צבעי רקע מהתמונות), מגזין.
- **עריכה**: פריסה אחרת לעמוד, ערבוב, כיתובים, הזזה ומחיקה של עמודים, "עיצוב חדש" לכל האלבום.
- **הדפסה**: PDF ב-300DPI, בגדלים 20×20, 25×25, 30×30, 28×21.5, A4, עם אפשרות ל-Bleed של 3 מ"מ.
  מספר העמודים הפנימיים נשמר זוגי.

## הרצה
אין צורך בהתקנה. מכיוון שהקוד משתמש ב-ES modules צריך שרת סטטי:

```bash
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

### פרסום ב-GitHub Pages
ב-Settings → Pages בריפו לבחור **Source: GitHub Actions**. כל push ל-main יפרסם את האתר.

## הערות
- תמונות HEIC מאייפון נתמכות רק בדפדפן Safari. בדפדפנים אחרים יש להמיר ל-JPG
  (או להגדיר באייפון: הגדרות → מצלמה → תבניות → "התאמה מרבית").
- הנתונים נשמרים ב-IndexedDB של הדפדפן. ניקוי נתוני האתר ימחק את האלבומים.
